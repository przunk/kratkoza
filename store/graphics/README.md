# Store graphics

Assets for the Google Play store listing (**Grow users → Store presence → Main store listing**).

## Files and Play Console mappings

| File here | Play Console field | Specifications |
| --- | --- | --- |
| `play-store-icon-512.png` | **App icon** | 512×512 px, 24-bit PNG without alpha channel |
| `feature-graphic-1024x500.png` | **Feature graphic** | 1024×500 px, 24-bit PNG without alpha channel |
| `*-store.png` | **Phone screenshots** | 1080×1600 px (1.48:1), 24-bit PNG, padded from 720×1600 |

## Generation

- **Icon & Feature Graphic**: Generated by `scripts/make-store-assets.py` from the project's own Slate palette (`ui/theme/Color.kt`).
  ```bash
  python3 scripts/make-store-assets.py
  ```
- **Screenshots**: Rendered directly from Compose in `StoreScreenshotsTest` without a physical device, then padded to 1080 px wide by `scripts/fit-store-screenshots.mjs` to satisfy Google Play's 2:1 aspect ratio and 1080px short-side rules.
  ```bash
  ./scripts/test-kratkoza.sh
  node scripts/fit-store-screenshots.mjs store/screenshots/*.png
  ```
